Accuracy = (TP + TN) ⁄ all = (44+40) ⁄ 100 = 84% — one number, hides who got hurt.
Precision = TP ⁄ (TP + FP) = 44 ⁄ 50 = 88% — "when it cries sick, how often is it right?"
Recall = TP ⁄ (TP + FN) = 44 ⁄ 54 = 81% — "of all truly sick people, how many did it catch?"
F1 = the balance of the two — one score when both errors matter.
CHOOSING IS ETHICS, NOT MATHS  A missed disease (FN) costs a life; a false alarm (FP) costs one extra test. Screening should chase recall. A spam filter fears blocked real mail — it should chase precision. Same table, different duty.
