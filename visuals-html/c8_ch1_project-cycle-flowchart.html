The AI Project Cycle — four stages, one honest loop
What a working team produces at each stage, and the question that ends each stage. Nobody moves on with an unanswered question.
STAGE 1 PROBLEM SCOPING output: a sharp problem statement
Who has the problem? Name the people, not "everyone".
What exactly? An outcome to change — not a solution yet.
Where & when? Places, times, seasons it appears.
Why worth solving? The cost of doing nothing.
↓
STAGE 2 DATA output: a collected, audited dataset
Collect with consent — and record how you asked.
Audit the guest list: who is over-represented, who is missing?
Label carefully — wrong labels teach the machine wrong.
↓
STAGE 3 BUILD & TEST output: a model + an honest accuracy number
Train on examples the machine can learn from.
Test on examples it has never seen — that is the only honest score.
Record the failures, not only the percentage.
↓
STAGE 4 REFLECT & IMPROVE output: a decision — ship, fix, or stop
Where did it fail? For which group, at which moment?
Improve one thing — data, labels or the goal itself.
Say the limits out loud before other people find them.
↻THE LOOP RULE: Stage 4 sends you back to Stage 1 with sharper questions — every real AI system cycles these stages many times. A team that skips a stage is not building faster; it is scheduling a surprise.
