Three nested boxes — and where the great divide cuts
Every deep-learning system is machine learning; every machine-learning system is AI. But plenty of AI is neither.
ARTIFICIAL INTELLIGENCE
Any machine doing things we used to need human judgement for — including old-fashioned rule-followers.
a lift with floor buttonsa thermostata scripted helpdesk
MACHINE LEARNING
Systems that improve from examples instead of hand-written rules.
spam filterprice predictor
DEEP LEARNING
Many layered learning pieces — powerful on raw pixels, speech, text; hungry for enormous data.
voice assistantessay-writing chatbot
THE GREAT DIVIDE — ASK IT OF EVERY MACHINE

Which side is it on?

Rule-basedA person wrote every step. It never improves until a human rewrites it.
Learning-basedThe system found the pattern in examples. It changes as data changes.

The honest test: "If this machine keeps meeting new cases, will it ever get better on its own?" No → rule-based. Yes → learning-based. The lift is AI by the widest definition — it will never learn anything.
