The model family map — every AI system lives on one branch
T10-01 puts ten real products on this map. Two trunks first, then the learning trunk splits three ways, and each split owns its own kind of task.
Rule-based
A PERSON WROTE EVERY RULE
Behaviour is typed by hand: IF this THEN that. It does exactly what it is told — and never gets better on its own.
Fixed logic
Every rule visible, testable, and frozen until a human rewrites it.
LIFT CONTROLLERSCRIPT BOTTAX SLAB CALCULATOR
Learning-based (machine learning)
THE SYSTEM FINDS THE PATTERN IN EXAMPLES
Given many examples, it tunes itself — improving with data, and inheriting the data's flaws.
Supervised — examples come with correct answers (labels)
Learn the link from input to known answer.
CLASSIFICATIONREGRESSIONSPAM FILTER · MARK PREDICTOR
Unsupervised — no labels, just structure
Find natural groups or co-occurring pairs nobody labelled.
CLUSTERINGASSOCIATIONVIEWER GROUPS · KIRANA BASKETS
Reinforcement — learns by acting and being scored
Try → reward or penalty → adjust. Game-like feedback loops.
GAME AGENTSROUTE OPTIMISERS
HOW TO PLACE ANY PRODUCT: ask three questions in order — 1) Does it improve from examples? (No → rule-based.) 2) Were the training examples labelled? (Yes → supervised; the answer type tells you classification vs regression.) 3) Did anyone label, or is it finding structure / chasing rewards? → unsupervised or reinforcement. Deep learning is not a fourth trunk: it is a technique for building the learning trunk with many layers.
