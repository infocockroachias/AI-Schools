Three no-code tool types — and their honest limits
Every no-code AI tool you will ever meet is one of these three families. Match the problem to the family, then read the limit before you trust the output.
Image Classifier
SORTS PICTURES INTO GROUPS
INPUT→OUTPUT

A photo, drawing or scan → one label from a fixed list ("healthy leaf", "blighted leaf").

HONEST LIMIT  Only knows the groups it was trained on; new angles or lighting it rarely saw will fool it.
Chatbot
WRITES WORDS BACK IN SENTENCES
INPUT→OUTPUT

Your message in words → likely words arranged into a fluent reply (also: summariser, translator, text generator).

HONEST LIMIT  Predicts plausible words — it can sound right and still be wrong (a hallucination). Verify every fact.
Data Predictor
ESTIMATES A NUMBER FROM NUMBERS
INPUT→OUTPUT

Past records as numbers → an estimate of a future value ("next week's demand: 112 crates").

HONEST LIMIT  Assumes tomorrow resembles the past; a pattern shift (new rule, new season) breaks it silently.
MATCHING RULE: start from the problem, not the tool — "what would the input be? what kind of answer do we need?" A brilliant tool matched to the wrong problem produces confident nonsense.
