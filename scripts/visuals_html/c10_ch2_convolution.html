Worked patch (rows 2–4, cols 2–4): 8×150 − (40+95+120+190+200+155+80+60) = 1200 − 940 = 260 — a strong positive response: dark-to-light edge running through the centre.
Why layers matter: one kernel sees only tiny patterns. Stack them — edges → corners → textures → object parts → objects. That stack is a CNN, and every layer is still just multiply-and-add.
