# visualgeneration.md — PRATIMAI Visual Registry & AI-Regeneration Prompts

**Purpose.** Every diagram/infographic in the PRATIMAI handouts is built **HTML-first**: a self-contained HTML file (brand fonts + PRATIMAI palette, no external requests) is rendered to a PNG with Playwright (`scripts/visuals_html/shot.py`, device-scale-factor 2) and embedded into the Typst book with the `figure-visual()` component. This file is the **single registry** for replacing any visual with an AI-generated image later: each entry carries the class, chapter and page where the visual lives, its caption, its file name, its aspect ratio, and a detailed regeneration prompt.

**Replacement workflow (AI images later).**
1. Pick the entry below → note its **file name** and **aspect ratio**.
2. Generate the image with the prompt (add your school's language; keep the palette).
3. Save it **under the same file name** into the book's `visuals/` folder (e.g. `scripts/ai_handout_c10/visuals/c10_ch1_model-families-map.png`).
4. Recompile: `typst compile --font-path fonts main.typ main.pdf` — no Typst edits needed.
5. Re-run the whitespace audit (`scripts/run_audit_c8.py <tag> <pdf>`) — a replacement with a different aspect ratio reflows the page; correct the page entry here if it moves.
6. Commit + push (standing rule).

**Naming convention.** `<class>_<chap>_<slug>.png` — class (`c6`…`c10`), chapter number, short slug. HTML sources live in `scripts/visuals_html/<name>.html`. The HTML is itself a living spec: it pins the exact text, hierarchy and palette an AI image must reproduce.

**Shared style contract (put at the end of every prompt).** *Flat vector educational infographic, clean geometry, generous whitespace, zero overlapping elements; palette: deep teal #0A3A47 / teal #0F4C5C / teal-mid #2E7286 / teal-tint #EFF6F7 / accent amber #E36414 / amber-deep #B94F0B / warm cream #F7F1E3 / paper #FDFBF7 background; sans-serif typography (Nunito-like), no photorealism, no 3D, no drop shadows heavier than 10% opacity, no stock-photo people, English labels rendered EXACTLY as listed, no watermark, no logo.*
